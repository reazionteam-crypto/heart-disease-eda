# Dataset

The dataset used in this project is the **Heart Disease dataset**.

## Source

The original dataset is available on Kaggle:

[DOWNLOAD DATASET](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset?select=heart.csv)

## Usage

After downloading the dataset, place the CSV file in this directory with the following filename:

```text
heart.csv
```

## Important Note

The dataset file itself is not included in this repository. It is excluded through `.gitignore`.

The notebook expects the dataset to be available at:

```text
data/heart.csv
```

Please download the dataset from the original source and place it in the specified location before running the notebook.
